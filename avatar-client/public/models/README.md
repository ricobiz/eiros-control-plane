# Avatar model slot

Place the evaluation avatar at `public/models/avatar.vrm`. The runtime also accepts any local `.vrm` through the file picker or a URL through `?model=https://.../avatar.vrm`.

The portrait supplied for the project is the visual target for the custom avatar. It is not itself a rigged 3D asset; exact identity reconstruction is intentionally outside V0 runtime implementation.

## Bundled evaluation fixture

`avatar.vrm` is `AvatarSample_A_1.0.vrm.glb` from VRMMetalKit, originally AvatarSample_A © pixiv VRoid Project. It is bundled only as a permissively redistributable evaluation fixture (VPL 1.0 metadata permits redistribution/modification). It is not the project's custom character.
